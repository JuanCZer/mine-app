# Matriz de controles de seguridad

**Revisión:** 18 de octubre de 2026.

**Base:** [OWASP ASVS 5.0.0](https://github.com/OWASP/ASVS/tree/v5.0.0).

Esta matriz relaciona controles aplicables con evidencia del repositorio. No es una certificación ASVS ni afirma que el entorno de producción esté listo. Todavía debe definirse formalmente el nivel ASVS objetivo; por la sensibilidad declarada de la aplicación, las decisiones sobre MFA, monitoreo y transporte deben resolverse antes de producción.

Estados:

- **Verificado localmente:** implementación y prueba documentadas en el repositorio.
- **Implementado con puerta operativa:** el código está comprobado, pero depende de infraestructura o ejecución en el entorno objetivo.
- **Parcial:** existe una parte del control y se documenta lo que falta.
- **Pendiente:** no hay evidencia suficiente para declararlo satisfecho.

## Evidencia que todavía falta

- Reporte de integración contra el PostgreSQL objetivo con TLS verificado, autenticación, ownership y las cuatro fases.
- Instalación limpia, segunda aplicación de `apply.sql`, backup/restore y prueba de rollback transaccional.
- Evidencia del entorno de proxy, CSP aplicada, keyring compartido, monitoreo y saneamiento de perfiles de navegador.
- Decisión formal sobre nivel ASVS objetivo, MFA y cobertura de auditoría de autorizaciones.
